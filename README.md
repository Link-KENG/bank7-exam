# 银行从业 · 七套卷在线答题

银行业专业人员职业资格考试（初级）在线刷题站，覆盖两大科目、每科 7 套真题卷。

**在线使用：<https://link-keng.github.io/bank7-exam/>**

## 板块

| 板块 | 科目 | 每套题量 |
|---|---|---|
| 法规 | 银行业法律法规与综合能力（初级） | 125 题（单选 80 × 0.5 分 + 多选 30 × 1.5 分 + 判断 15 × 1 分 = 100 分） |
| 个人理财 | 个人理财（初级） | 115 题（单选 80 × 0.5 分 + 多选 25 × 2 分 + 判断 10 × 1 分 = 100 分） |

每套卷取自天一新奥《考点精析与上机题库》"真题精选（一）~（七）"。

## 功能

- **做完一题立即出答案**：单选/判断点击即判，多选选好确认后即判，并展示解析
- **每套卷作为一次考试**：按板块 → 套卷进入，全程计分，可提前交卷（未答按错计）
- **历史记录**：全部考试记录保存在本地（localStorage），首页显示每套最高分，可点开回顾每道题的作答与解析，可重考、可清空

## 题库整理说明

原扫描版 PDF 中存在重复页码（同一页被打印两次），已按内容指纹自动识别并删除，确保**不重不漏**：

- 《25法规七套卷》删除重复页 2 页，并从单册《7法规》补齐第 7 套缺失的 16 道单选
- 《25个人理财七套卷》每套删除重复扫描页，共 7 页

## 本地运行

```bash
cd site
python -m http.server 8000
# 打开 http://localhost:8000
```

纯静态站点，无需构建。题库数据在 `site/data/*.json`，历史记录存于浏览器 localStorage（键 `bank7_history_v1`）。

## 更新流程

题库解析脚本在 `../scripts/`（OCR 提取 → 解析 → 合并答案 → 校验），修改数据后：

```bash
git add data && git commit -m "update data" && git push
```

GitHub Pages 直接从 main 分支根目录自动部署（仓库根目录即站点文件）。
